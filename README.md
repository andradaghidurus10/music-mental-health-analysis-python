# Music & Mental Health Analysis (Python)

This project explores the relationship between music listening behavior and mental health indicators using clustering techniques.

Technologies used:

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

Project steps:

- data cleaning and preprocessing
- handling missing values using SimpleImputer
- feature standardization using StandardScaler
- determining the optimal number of clusters using the Elbow method
- clustering using the KMeans algorithm
- clustering evaluation using Silhouette Score
- dimensionality reduction using PCA for visualization

Results:

The project identifies psychological user profiles based on anxiety, depression, insomnia and OCD indicators, as well as music listening behavior patterns.
